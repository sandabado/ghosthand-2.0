## Result

Drain now places an instanced field of leeching filaments between the camera-body and a distant ceiling. Their origins sit below the first-person view; no bound person is depicted. Unequal paths, thicknesses, tension, and upward pulses make the burden visible before release.

There are **28 strands × 32 segments**. A core field and a soft envelope render **1,792 GPU segment instances** in total, with **672 seeded release motes**. A separate invisible, slightly broadened rest-space proxy supports practical raycast hit areas; its instances are not included in the 1,792 rendered segment count. This is not 1,792 separate mesh components.

Moving over a filament raycasts the instanced field and maps the hit segment back to one of the fourteen illustrative audit fixtures. The selected thread exposes its name, example rate, and meaning in the DOM trace panel. A native disclosure also exposes every audit item to keyboard focus and explicit selection. Keyboard selection is not overwritten by a stationary pointer. Picking stops once release begins.

Look up is a deliberate upward pointer/touch stroke in its own interaction area. At least 64px of upward travel must exceed lateral travel. Short movement, sideways movement, pointer cancellation, lost capture, blur, and ordinary page scrolling do not release the threads. ArrowUp within the focused zone and the explicit keyboard alternative invoke the same guarded release action.

The release briefly loads the tension, then breaks the filaments in a staggered body-to-ceiling cascade. Detached fragments recoil and dissolve; the group is not merely scaled away. Candle-green light opens through the local atmosphere as the blue burden clears. The next gate remains unavailable until the local dawn has settled.

## Accessibility and reduced motion

The deliberate gesture area uses `touch-action: none` and pointer capture only for its own rite. It does not consume ordinary page scrolling as a release command. Cancellation clears partial input. Accessible status changes describe discrete phases rather than announcing every frame.

The fourteen audit options retain native focus/activation semantics, minimum 48px targets, and visible focus rings; the disclosure summary is at least 44px high. The next action remains guarded by the same completion state for every input path.

Reduced motion preserves the same route and controls. Its release directly selects the completed local state, without animating the camera, recoil, or motes. The hidden World stays mounted, the static fourteen-state storyboard remains available, and a **static candle-green backdrop confined to the free Drain** communicates the dawn without motion. The bound state remains still and dark.

Changing the system preference during an active release also settles that local rite immediately. It records one static completion, rather than leaving the hidden animation running. A preference change while bound never releases the threads.
